# 互动画像与适配

这是工作方法，不是经过验证的人格量表或恋爱预测模型。先理解本次言语行为，再参考跨情境的模式；不要为了填表搜集无关私人信息。

## 最小画像结构

每项只记录会改变回复的内容：

| 字段 | 记录方式 |
| --- | --- |
| 观察 | 实际说了或做了什么；用必要的短摘录或准确转述 |
| 来源 | 本人明确表达、实际互动、主页自述、AI转述、模型假设；注明日期/场景 |
| 判断 | 对沟通偏好的暂定解释，限定话题与状态 |
| 支持程度 | 明确表达／跨情境重复观察／单次弱线索／未知；不伪造概率 |
| 替代解释与反证 | 忙碌、话题不熟、关系阶段、应用使用习惯；相反的实际信号 |
| 适配动作 | 对下一句的具体影响：缩短、展开、接情绪、分享、询问或等待 |
| 更新条件 | 哪种新表达会推翻或缩小该判断；发生矛盾时如何复核 |

更稳定的偏好、当下状态和双方共同形成的互动模式分别记录。多条连续消息可能来自同一情境，不能装作多次独立证据。对方直接纠正时更新，不用旧标签解释掉反例。

## 可观察维度

- **话题与展开度**：主动引入或反复延续什么；只回答什么；哪些话题目前不愿展开。职业和爱好只是入口，不自动决定对方想聊什么。
- **信息密度与轮次**：喜欢短句分发、完整叙述还是具体问答。优先看承接与新信息；字数、秒回、已读不是独立的兴趣评分。
- **情绪与支持方式**：正在庆祝、吐槽、求方法、求陪伴还是需要空间。先依明确措辞；不清楚且会影响回复时轻问需求，不每次都套用咨询话术。
- **玩笑与表情**：共同理解的梗、是否会接续调侃、是否有不舒服的反馈。一次笑脸不等于接受暧昧、性暗示或身体评价。
- **互惠与主动性**：是否补充自己的细节、追问用户、主动续话、提出替代安排。积极信号支持继续了解，不等于已确认恋爱意愿。
- **活动与安排**：共同活动或并行陪伴、计划提前量与可行性；区分愿意参加、经常参加和已经答应。
- **边界与关系目标**：只记录明确表达；当前拒绝优先于历史热情。关系目标不同不靠话术修正对方。

## 从信号选择回应

以下是场景化候选动作，不是给人固定分型，也不是研究证明的最佳话术。

| 当前信号 | 优先尝试 | 避免的跳跃 |
| --- | --- | --- |
| 主动追问具体问题 | 先直接回答，按问题深度展开，可补一点真实经历 | 因职业就讲长课，或不答问题强行聊生活 |
| 分享小事或开心结果 | 点出有趣细节，按用户实际感受回应；有真实关联再分享自己 | 把每个分享变成采访或过度夸奖 |
| 叙述烦恼但没求建议 | 先回应实际处境，留一点空间；确实不清楚再问要不要一起想办法 | 诊断情绪、立即给方案、凭空说自己经历过 |
| 简短但持续提供新信息 | 保持简洁，围绕同一话题继续 | 判定冷淡、升级暧昧来刺激回应 |
| 多次只有礼貌收尾且无主动延续 | 降低追问密度，合理结束；有新素材和授权时再判断是否跟进 | 断言心理原因、连续催促或循环问AI |
| 明确忙/累/暂时不聊 | 按她的实际要求收束 | 故意计算晚回时长，或把状态写成永久性格 |
| 主动玩梗且双方接得住 | 适度接梗，保留自己的表达 | 机械复制字数、笑声、表情或加大冒犯程度 |
| 明确双向兴趣且安排可行 | 提一个具体、轻松、容易拒绝的活动建议 | 仅凭同城、笑脸或AI推荐就直接约见 |

## 反证与修复

- 暂定判断须能被新信息推翻。若对方反应与预期不同，先检查是否答非所问、说太多、事实错误、关系阶段不合适，再更新画像。
- 对语气或边界被明确纠正，简短承认并调整，避免解释自己的善意占据对话。发送失误先核验实际结果，不删除重发以制造没有出错的假象。
- 真实匹配是双向的。双方节奏或价值期待确实不同，应让用户看见差异，不无限优化迎合。
- 照片只用于用户授权的外形与展示评估，不作为性格、依恋类型、心理健康或恋爱意愿证据。自述MBTI可以当话题，不能从它自动选择固定策略。
