# 教学课件

与 `Presentations` 组合使用。围绕学习迁移而不是资料覆盖组织：先备知识与目标 → 心智模型 → 分步解释 → 示范例题/案例 → 学习者练习 → 反馈 → 回顾与延伸。

按 [live/read/hybrid 使用模式](../presentation-studio/references/authoring-modes.md) 区分教师带领与自学，保留本技能的练习/反馈节奏；有参考作品时读 [参考转译](../presentation-studio/references/reference-translation.md)，定量教学图按 [图形真实性](../presentation-studio/references/chart-integrity.md) 区分精确编码与概念示意。

- 每个学习目标应能观察或检验，不写“了解”“熟悉”作为唯一结果。
- 新概念先给直觉和边界，再给正式定义；示例与定义紧邻。
- 每 5–10 分钟设置一次回忆、判断、操作或讨论，不让整套课件只有讲述。
- 现场页减少文字，教师说明进入备注；自学版可以增加解释但仍保持分段。
- 示例与练习的难度逐步增加，答案不要和题目同时抢占注意力。
- 不用图片装饰替代解释；图像、示意图和类比必须服务于具体学习目标。

基础渲染验证由 `Presentations` 完成；用户要求独立审阅/修复，或涉及高风险决策、关键定量结论及复杂改版时加载 `deck-review`，重点检查目标覆盖、先备知识、认知负荷、练习质量和可读性。
