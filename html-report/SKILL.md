# HTML 专题报告

交付可独立阅读的报告，而非把幻灯片逐页装进网页。本技能可独立完成内容组织、HTML 构建与交付，不要求加载 PPT 技能栈。用户明确要求网站发布、数据分析或 Google 文档时使用相应能力；不要因交付 HTML 自动上传或发布。

## 形成阅读方案

从已有任务信息确定受众、阅读后要理解或决定什么、阅读路径、资料范围、截至日期、模板约束、是否要求离线及打印。只追问影响成果的缺项，其余采用并说明合理默认值。

- **快速导读**：首屏交代问题、核心判断、关键证据、行动及成立条件；提供可直达专题的目录。导读能独立回答“为什么值得读”。
- **完整自阅**：总览 → 专题 → 机制/比较 → 条件与反例 → 行动 → 方法与来源。按认知任务分章，可用长页；保留推理链和可回跳引用。
- **现场展示**：扩大关键图文、减少同屏信息，提供清晰段落定位；完整论据仍留在后文。不要强制 16:9、固定视口高度或“一页一观点”。

复杂材料先画问题与章节地图，再按专题下钻。需选择模块和拆分条件时读 [内容与设计](references/content-and-design.md)。

## 证据与设计

建立紧凑的证据记录：`claim_id → 主张类型 → 数值/单位/口径/期间 → 来源定位 → as-of → 局限 → 使用章节`。事实、估计、推断、建议使用明确措辞；正文把证据、解释、行动和成立条件连起来。已有内部业务材料只作为本次输入，不成为公共模板的默认事实。新研究按任务采用可用检索能力，不把示例主张当成已核验事实。

先判断参考作品是**严格模板**还是**灵感参考**。严格模板遵守其品牌与版式契约；灵感参考只提炼语义色、字级、留白、密度、阅读顺序和图表语法。不要默认复制品牌、内部材料，或把蓝色渐变、圆角卡片当成报告标准。必要时以更适合主题的编辑式、技术手册式或品牌风格替代。

## 构建

- HTML 源码包含真实正文、最终数字、图表及来源。JS 只增强导航、折叠和可选动画；禁用 JS 后全部核心内容可读。不可用空计数器、点击取数或 canvas 单独承载核心证据。
- 默认语义化 `header/nav/main/section/figure/table/footer`，合理标题级别、中文字体与行距、文本标签、键盘操作和可见焦点。锚点可定位章节；宽表在屏幕有明确横向滚动入口，在打印时换行或提供可打印拆分版。
- 多列表格按内容分配列宽，区别短编号、状态和长说明；避免把列宽写在会同时命中整行表头的宽泛 `th` 选择器上。涉及列宽、长中文或筛选时，按 [表格布局与逐表验收](references/build-and-check.md#表格布局与逐表验收) 检查实际渲染，不能只看首屏或页面是否横向溢出。
- 图形从同一数据源生成，或逐项核对表格与几何尺寸。实测、预测、示意有文字/线型区分；颜色不单独承担意义。线性条形从零起、共用比例；对数轴只接受正数；缺少中间贡献时不能画成分解瀑布。详见 [构建与验收](references/build-and-check.md)。
- 尊重 `prefers-reduced-motion`；动画不承担信息。打印需包含全部章节、折叠正文、最终图表与来源，禁用动画、移除滚动/固定高度造成的裁切。原生 `details` 用 `open` 保证无 JS 可读，JS 增强后才允许用户收起，并在打印前展开。
- 单文件离线交付内联必要 CSS/JS/SVG，避免 CDN、远程字体和运行时请求；其他用途按要求管理资源，不强制全部离线。

可从 [完整 starter](assets/report-starter.html) 开始：一个明确标注合成数据的容量方案报告，组合结论、指标、静态 SVG、机制、比较、阶段路线与来源。它是可裁剪示例，不是强制模板；定量图表可沿用其表格—几何审计契约。

## 验收与交付

运行 `python scripts/audit_report.py <report.html> --json`；离线单文件加 `--single-file`。该脚本检查锚点/本地资源、部分静态可读风险、打印与减动声明，以及**已采用审计契约的条形图**；不证明所有内容或图表正确。按 [验收说明](references/build-and-check.md) 补做语义、阅读与视觉检查。

有合规浏览器条件时检查桌面/窄屏、键盘、禁用 JS、减动与打印预览；修复裁切和漏章。受环境限制时明确区分源码/计算检查和未执行的视觉/打印检查，不能把 CSS 存在说成已测 PDF。

交付 HTML、必要本地资源及简短说明（主结论、输入与截至日期、已做检查、待核验限制）。除非用户要求，不额外制造网站工程、发布流程或庞大模板库。
