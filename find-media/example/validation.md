# 验证记录（2026-10-21）

本次用 Python 3.13.7、Pillow 11.3.0、Node 24.19.0、trace.moe-id 2.0.0、sharp 0.35.4。视频由 imageio-ffmpeg 0.6.0 附带 FFmpeg 7.1 essentials 构建处理。没有私密素材入库。

## 自动测试

31 项通过。真实 FFmpeg 生成两种 lavfi 画面拼接，检查切镜/无切镜、从 2 秒起读的切点仍为输入 3 秒、预算下未处理镜头、镜像两次还原和局部像素比对、中文空格路径实际官方特征提取。其余测试覆盖字幕多命中/ASS/VTT、不同 episode 类型和低分不升级、空结果、网络超时、402 停止、重试预算、缓存、额度耗尽、脱敏 /me、title_only、双来源逐帧保持独立、变速不盲推区间、连续区间需原片连续证据。

其中两段“来源”是生成画面；API 返回由 fixture 隔离，证明逐帧不串源的程序契约，不证明任何真实两部动漫混剪的识别准确率。无匹配/低分/额度/超时是离线 fixture，未故意消耗在线服务制造错误。真实视频未进行完整多作品混剪在线识别。

第一次测试在系统临时目录遭 FFmpeg 写权限拒绝；改用独立任务临时目录后所有真实视频测试通过。官方 quick_validate 默认 Windows GBK 失败，设置 PYTHONUTF8=1 后通过；未改校验器。

## 在线核验

- anime-live.json：官方 API 文档公开演示图，本地提特征，1 次搜索取得作品/集数候选/数据库 at。实际看过原图、命中预览图及预览视频两帧，构图/动作/背景吻合。初次预览 403 后，以客户端 User-Agent 有界重读得到 200。仅数据库版本锚点；集数仍独立未确认，未看完整原集，未定位连续区间。预览 URL 短时失效，截图/视频不随仓库发布。
- plot-title-only.json：合成剧情描述检索，Paramount 官方剧情页支持片名/年份，未给假时间。官方页可访问不证明地区实际播放。
- game-candidate-feedback.json：合成手机游戏线索，查询真实候选资料；看过 MobyGames Android 截图及发行页、同期 iPhone 玩法报道。正文一处 403，其他来源成功；网页标题作品年份和 Android 发行年份不同，分开记录。第二轮否定是测试反馈，不是用户真实反馈，也不是用户举例游戏的答案。

## 尚未验证 / 不支持

没有全网识图准确率或整库本地索引验收；真人仅剧情到片名，未用真实影视视频定位；未对任意抖音/小红书链接做媒体提取；OCR/ASR、TMDB/IGDB API 是按需外部能力，未安装或验证。跨发行版时间误差未知。游戏候选与截图对照有实际来源，童年游戏最终答案仍未知。案例结果不可作为将来输入的默认事实。

## 独立前向评估与修复

独立评估使用合成旧手机线索，检索了 Dungeon Hunter II、Heroes Lore、Titan Quest 等；对第一候选的合成否定后保留排除记录并检索新候选，没有默认 Java。剧情请求通过官方页确认片名、保持时间未知。可读资料与无法查看截图分别记录。

评估发现区间可接受越界/NaN 锚点、截断 HTTP 响应未归类、额度耗尽阻止缓存、全查询失败退出码不一致，均已修复并加入可复现测试。另外修复多段表格被证据段落打断的问题。官方 quick_validate 通过，全量严格治理 40 个 Skill、0 错误。结构检查不等于识别正确率。

二次独立复核进一步覆盖单锚点越出输入范围和 HTTPError 错误体截断，均修复并加测试；测试总数最终以 31 项为准。
