# 找记忆中的游戏

先搜索现有线索，再问少量有效问题。“小时候/旧手机”不能默认 Java/J2ME，有龙/装备不足以认定作品。描述、截图、可读视频都可作线索，模糊年份不能硬过滤。

维护任务内账本：明确记得、大概记得、不确定、用户修正、已否定候选及原因/版本。查不到也继续可执行检索并记录已查平台/语言/年代和缺口；不把没有记录写成不存在。剧情找影视复用此方法，再读影视参考。

从独特玩法循环、视角、UI、关卡/道具/剧情、操作方式检索中外名称和别名。优先官方、开发商/发行商、说明书、历史商店或可访问存档；MobyGames、IGDB 补平台/发行/截图交叉核验，社区仅作线索。IGDB API 要 Twitch 凭据，无凭据走公开查询，不强迫注册，不部署 RomM。

给少量有证据候选，每项有名称/别名/具体版本、平台与发行年代来源、符合/冲突/未知、链接。发行年不是游玩年。给对应平台真实截图/玩法视频或带图页面；能读到图才描述观察，只有标题就注明未看图，别拿重制版或另一平台 UI 代替。

候选形成后选最能区分的 1–3 问：实体按键/触屏、画面视角、即时/回合制、在哪个人生阶段玩过。用户不懂系统就问可回忆特征；Java/J2ME、Symbian、BREW、早期 Android/iOS、预装、移植、山寨名都保持待证。

反馈后更新：明确否定不重复推荐；若同系列另一个版本，说明差别与新证据，不能绕过否定。允许记忆修正，不迎合候选篡改线索。通常 unresolved，用户确认/独特细节与可靠来源闭合后才 title_only。排除状态和网络状态互不替代。确认后给对应原版官方/商店/资料入口，下架则说明，不以同名新作、私服或 ROM 下载代替。
