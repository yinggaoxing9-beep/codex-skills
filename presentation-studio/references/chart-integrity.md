# 图表的数值与图形真实性

构建者保存原始数值、单位、期间、口径、状态（实测/披露、估计/预测、示意）及证据 id；审阅者同时检查数据和最终渲染。标签正确不等于图形正确。

## 值到图形的映射

- **长度/位置**：同图同系列采用同一映射和基线。线性条形从零起，长度 `L = plot_width × value / axis_max`；负数从共同零点向相反方向延伸。需截断坐标时优先改用明确刻度的点图/折线图并醒目标注，不能用截断条暗示比例。对标签、轴值与形状端点抽样复算，尤其检查手工形状和动画最终状态。
- **面积**：数值编码面积时，圆半径与数值平方根成比例，不能把半径直接乘倍率；正方形边长同理。图例说明面积代表什么，立体透视不用于精确比较。
- **角度**：完整占比的扇区角度为 `360° × value / total`；确认同一分母、互斥且加总合理。非完整占比或含负值不用饼图。圆环图的弧长/角度应与占比一致，非数字装饰不冒充占比。
- **对数**：值必须大于零，刻度按明确底数递增；零和负值不能画成合法对数刻度，也不能静默加常数。零值单列或改用其他图型；优先点/线图，说明“等距离表示相同比率”，不能宣称长度仍代表数值的绝对倍数。
- **瀑布**：每项增减必须有可核验值与一致的累计基数，终点等于起点加各变化量。缺少中间值时只展示起终点和未量化的驱动机制；不要为填满瀑布编造精确中间柱。

## 状态、尺度和不确定性

实测与预测用标签加线型/填充区分，标出预测起点；示意图在图题旁写“示意，形状不编码数值”，不配精确数轴暗示精度。区间用区间带/误差线或直接写范围；缺失值保持缺失，不当零、不连成确定走势。双轴、分面和跨页比较检查单位与范围，轴不一致需说明，不能仅靠相似柱高引导判断。

## 教学反例与修复

以下数字纯为教学，不代表任何行业判断：同一零基线的横条，`1×` 与 `50×` 不能等宽。若上限为 `50×`、绘图区宽 `8 in`，两条应为 `0.16 in` 和 `8 in`；小条标签放外侧，不通过最小宽度美化成相同比例。若极差导致读不清，改为有合法正刻度的对数点图，或直接排数值并取消比例图形。网页动画需检查结束宽度，不能只读初始 `width=0`。

另一反例是将缺少中间披露值的降本过程画成精确瀑布；应改为两端比较图加无量化阶段箭头。两类修复均需核对最终图形，不以“示意”脚注掩盖带精确标签的错误编码。

## 自动检查边界

`deck-review/scripts/deck_audit.py` 只做 PPTX 结构与启发式静态检查，不验证长度/面积/角度映射、不重算图表缓存/工作簿、不判断坐标轴合理性和预测状态，也不推断形状与文本标签的语义关联。把这些项目逐项写入人工/渲染检查记录；没有检查就写“未验证”。若以后扩展脚本，只对明确解析的数据结构和已验证的支持范围给出结论。
