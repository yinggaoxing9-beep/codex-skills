# live / read / hybrid 的编排与验收

沿用 deck-brief 的 `mode`。由观众如何使用材料决定密度，不用统一字数或固定页数判定好坏。字号、段落和图表容量取决于投影距离、画幅、输出设备、模板和任务；放不下先改变结构。

| 决策 | live：讲者带领 | read：读者独立判断 |
| --- | --- | --- |
| 信息编排 | 先给可复述结论，再依讲解顺序逐步揭示证据；一个主视线，必要时总览后局部放大 | 标题给结论，导语交代问题，证据与解释邻接；小标题、编号和交叉页码支持跳读 |
| 密度与节奏 | 主图和决定性标注优先；细节进入备注或可定位附录。允许停顿/过渡页，按实际讲解时长验证 | 可增加定义、比较表、方法摘要和反例；整合相关论证以减少翻页，但不缩字塞满；复杂证据仍可拆页 |
| 来源与成立条件 | 页内保留来源短标识、期间/单位，以及会改变判断的关键前提；完整引文与方法可在备注/附录 | 页内给出可识别来源、口径、日期和限定语，长引用可到明确页码的附录；关键含义不可依赖演讲备注 |
| 行动 | 口头请求可由页面突出“谁、何时、批准什么、触发/停止条件” | 缺席读者也能找到建议、授权范围、责任人和核验方法；推断与建议有可回查依据 |
| 验收 | 按预计设备/观看距离渲染并试讲：观众能随讲解追踪主图、复述当前结论及其关键条件，讲者可按时完成 | 关闭备注、不听讲解顺读和跳读：读者能重建证据到结论的关系、理解术语/口径、定位来源与反例并知道下一动作 |

来源脚注可以短，关键不确定性不能以“现场解释”为由隐藏。read 的自足性不是每页复印资料全文；重复定义可指向前文或词表，但关键条件应在判断发生处出现。

## hybrid：一条主路径与一层补充

先在 brief 的 `objective` 或已有说明文字中声明“现场主路径 + 自阅补充”或“自阅主路径 + 讲述提要”，不增加新模式字段。

- **现场主路径**：主体按 live 排列，保留推荐成立条件、关键口径与证据短标识；每个需要复核的判断标注如“方法/敏感性 → A2”。附录按 read 编排，能独立解释对应证据。备注承载讲稿，不能作为自阅唯一来源。不要把每页再复制一份密集版。
- **自阅主路径**：主体按 read 完成论证，利用已有目录、页码和讲者备注标明演讲选读顺序。省略讲读的页面仍在文件内；一份材料只维护一套数据与结论。

验收既要试走主路径，也要让不听讲解者沿标注查到完整解释；检查编号、引用、条件与主图口径一致。静态审计若需 `--mode live|read`，选与主路径相符的值；补充层仍按其实际用途人工检查，脚本不会自动识别层级。

## 何时拆页

当讲解需要同时来回指向多个独立问题，或独立读者无法在正常缩放下建立证据与解释的对应关系，就拆分、重排或移入附录。先用阅读任务验证，再决定页数；“更多文字”与“更少页数”都不是模式本身的质量目标。同一材料的差异见 [完整页例](page-examples.md)。
