# 五类可操作页例：资源选择教学案例

只在需要相应页型时选读。所有名称、日期、记录、数值和阈值均为**虚构教学数据**，不构成真实测试、预算或采购建议。下面展示编排、口径和对象规格；未生成 PPTX，不是渲染合格样板。可按任务更换画幅、素材与叙事，不把这些页面变成强制模板。

目录：1 结论总览（同材料 live/read） · 2 关键指标 · 3 阶段路线 · 4 机制图 · 5 比较矩阵。

## 共用素材与画幅

教学问题：一家虚构的业务团队要在方案 A（缓存改造）和 B（增加工作进程并调度）之间，选择是否批准 B 的六周试点，预算上限 8 万元；生产扩容另行审批。

最小证据账本示例，沿用 [契约](contracts.md)：

| id / kind | claim、source 与 as_of | scope / unit / confidence / limitations / based_on |
| --- | --- | --- |
| F1 / fact | 基线 80，A 120，B 160 任务/分钟；P95 分别 12、8、5 秒；来源：教学合成压测记录，虚构日期 2026-09-30 | 同一合成任务集、同一软件版；各方案在声明的负载与资源配置下运行 30 分钟、重复三次，各指标分别取中位数；失败率均≤1%；confidence：仅供教学。未提供逐次联合记录，分别汇总过线不能证明同次测试所有门槛联合达标。不同配置，不能归因于单一算法；无生产峰值/长期数据 |
| E1 / estimate | 年化运行成本基线 20、A 28、B 44 万元；B 试点单列 8 万元；来源：教学预算草算，虚构日期 2026-10-01 | 统一计入算力、软件及运维分摊；按稳定运行全年估算，非合同报价；试点不是自动追加到年化成本的同期间支出；置信度低；未估迁移收益；依据为教学预算输入 |
| F2 / fact | 试点验收目标为吞吐≥150 任务/分钟、P95≤6秒、失败率≤1%；来源：虚构需求记录，2026-10-01 | 是本案例的业务要求，不是行业标准；三个条件须在相同回放场景同时满足 |
| I1 / inference | B 的汇总指标达到门槛，可优先试点；逐次同场景联合达标尚待复验 | based_on: [F1, F2]；缺少逐次联合记录，不能外推到生产或推断统计显著性；需联合复验 |
| R1 / recommendation | 建议批准 B 六周、上限8万元的分阶段试点，暂不批准生产扩容 | based_on: [I1, E1]；按事先约定的同一回放窗口联合复验 F2，且合规/回退准备通过才放行后续预算；不达标则暂停下一批投入 |

`fact` 表示案例内的原始观测/要求，页上仍写“虚构教学数据”，不能让读者误认为真实实测。真实工作应换成可访问日志/需求来源，并保留样本、配置和不确定性。

无模板示例画布：13.333 × 7.5 in，四周安全区 0.55 in；标题区 y=0.45–1.25，主体 y=1.55–6.25，条件/页脚 y=6.35–7.05。坐标均为左上角；字号是待渲染的起点：live 标题30/正文20/来源11pt，read 标题28/正文16/来源11pt。深色正文、低饱和分隔、蓝色强调候选 B，橙色强调未通过的门槛；不靠颜色单独表达状态。所有文字、表、图、节点及连线为可编辑对象。

## 1. 结论总览：同素材的两种编排

### live：先让现场抓住请求

- **标题文案**：“建议批准 B 六周试点，上限 8 万元”。副标题：“汇总指标达到门槛，逐次同场景联合达标尚待复验”。
- **主区**：左侧 x=0.55、y=1.7、w=7.7、h=3.9，以大号短句呈现“B 汇总：160 任务/分钟；P95 5 秒”，下方放一句解释“汇总指标达到门槛，不代表同次联合达标”。右侧 x=8.65、y=1.7、w=4.1、h=3.9 是授权文本：“批准：试点8万元；暂不包含：生产扩容；负责人：教学项目组”。不用把两侧强制包进卡片。
- **条件带文案**：“按约定的同一回放窗口联合复验三项 F2 门槛，且合规/回退就绪才放行下一批预算；否则暂停”。放主体下方，不能只进备注。
- **页脚/备注**：页脚“虚构教学数据｜F1/F2：教学记录，2026-09-30/10-01；E1：预算估算”；备注放配置、三次测试取中位数的方法、成本范围、反对意见。完整方案比较可标“→ 附录 A1”。
- **阅读顺序**：建议/金额 → B 的关键证据 → 为什么只批试点 → 放行与停止条件；讲者再展开比较页。
- **适用/拆页条件**：适合现场启动讨论。若授权涉及多个不可逆事项或独立成本口径，摘要只保留当前决定，再拆授权明细页；不要靠缩小请求文字容纳所有条款。

### read：让缺席者能独立判断

- **标题**与 live 相同，保留同一事实与建议；主体重新组织，不是简单加小字。
- **导语** x=0.55、y=1.5、w=12.2、h=0.65：“目标是在失败率≤1%时达到≥150任务/分钟、P95≤6秒。B汇总指标达到门槛，逐次同场景联合达标尚待复验；不能据此批准生产部署。”
- **证据表** x=0.55、y=2.35、w=7.25、h=2.1：列为“基线 / A / B”，行为“吞吐80/120/160；P95 12/8/5；年化成本估算20/28/44”。列头分别注明单位；表注区分 F1 的合成观测与 E1 的估计。没有总体“已实测”标签把成本一起包进去。
- **解释与取舍** x=8.15、y=2.35、w=4.6、h=2.7：“B的汇总指标达到门槛，A成本较低但汇总表现未过线。尚缺逐次同场景联合记录，B年化成本估算也最高，因此先用8万元试点联合复验并检验生产代表性。”
- **行动与条件** x=0.55、y=5.4、w=12.2、h=0.8：“教学项目组分三阶段执行；每阶段按同一回放窗口联合复核 F2；不达标暂停后续投入；生产扩容需另批。阶段预算及责任 → 第3页；完整测试配置 → A1。”
- **来源**：页脚写“虚构教学数据；F1：合成压测记录，2026-09-30；F2：需求记录，2026-10-01；E1：预算草算，2026-10-01”。A1 必须随文件交付并包含记录和口径；关键条件已在本页，不能只在备注。
- **阅读顺序**：建议 → 目标/证据 → 取舍与限制 → 授权边界/下一步 → 来源。关闭备注后仍能理解为何不选A、为何只批准试点。
- **适用/拆页条件**：适合会前阅读或审批留档。若表与解释在目标设备上不能并读，拆为“决策摘要 + 选项证据”两页并互指；不是用现场版字号硬塞密集说明。

**同材料 hybrid**：采用 live 版为主路径，保留关键条件；把 read 版的证据表、解释和方法合并为附录 A1，而非逐页复制整套 live。主页面直接链接/标页码至 A1；A1 自足且与主路径共用数据。若用户主要用于传阅，则以 read 版为主并在备注标出讲述提要。

## 2. 关键指标：用正确比例解释吞吐差异

- **页面文案**：标题“B 的教学吞吐中位数为基线的 2 倍，仍需联合复验”；图题“声明配置下的持续吞吐（任务/分钟，合成观测中位数）”；图下“此图不比较成本或延迟，三项验收门槛见比较页”。
- **布局/对象**：左侧 x=0.55、y=1.7、w=8.6、h=4.3 为原生水平条形图；类别标签区宽1.0，绘图区 x=1.75、w=7.0。零基线，线性轴0–200，刻度0/50/100/150/200。基线80、A120、B160的条长分别2.8、4.2、5.6 in；等高0.5 in，端点直接标数。x=9.65、y=2.0、w=3.1、h=2.8 放“160÷80=2.0×”及“配置不同，不能归因于单一算法”。
- **来源/条件**：“虚构教学数据｜F1，2026-09-30；同任务集/软件版，配置不同，三次30分钟测试指标中位数；未覆盖生产峰值”。live 页内保留配置差异和未外推条件，完整配置进备注/A1；read 页内另写采样/聚合定义并指向 A1，不留给讲者补全。
- **阅读顺序**：标题 → 零基线与单位 → 三条端点 → 倍率 → 限制。柱长比80:120:160=1:1.5:2，禁止为美观等长。
- **适用/拆页条件**：单一可比量的选项差异。需同时解释P95或成本时另做图/比较页，不用三种单位塞进一张条图；极端量级差可改合法对数点图并解释倍率含义。

## 3. 阶段路线：用决策门连接预算

- **页面文案**：标题“8万元分阶段投入，未通过门槛即暂停”；三段：“第1–2周：复现，2万元，测试负责人”“第3–4周：受控试点，3万元，业务负责人”“第5–6周：验收，3万元，项目负责人”。这是计划估计，不是已完成进度。
- **布局/对象**：主体一条可编辑时间轴 x=0.8、y=2.55、w=11.8，共6周，每周1.967 in；三阶段各占等长两周。每段上方列产出：“可回放任务集/回退脚本”“限流接入/观测记录”“验收报告/扩容另审”。阶段之间用门形标记及标签“继续需同窗口联合复验F2通过 + 合规/回退通过”。下方为一条显式停止支路“未通过 → 暂停下一批，复盘后重审”。
- **来源/条件**：“虚构教学计划与预算｜E1/R1；2+3+3=8万元；阶段门槛来源 F2；扩容不在授权内”。没有证据支持完成度百分比，所以不画已完成进度条。
- **模式/顺序**：live 讲“先验证→受控使用→决定是否扩容”，再点门槛与暂停分支；read 在每段下方增加验收产物和负责人全称、明确门槛定义，并指向A1测试协议。阅读顺序始终左到右，门槛后才进入下一段。
- **适用/拆页条件**：有顺序与依赖的试点/实施计划。并行工作流或不同审批权超过一页可追踪容量时，拆“总路线 + 决策门清单”，不要把所有部门日程缩成甘特墙。

## 4. 机制图：区分链路示意与收益证据

- **页面文案**：标题“B 将等待任务分配给可用工作进程，瓶颈仍需定位”；图题“任务分配机制示意，不编码吞吐或成本”。
- **布局/对象**：四列原生节点及连接线，均在 y=2.25–4.65：入口 x=0.65、w=1.65 → 队列 x=3.1、w=1.85 → 调度器 x=5.75、w=2.0 → 工作进程池 x=8.55、w=3.85。工作池内画三个等大节点，并注明“示意数量，非真实实例数”。箭头标“任务入队”“取可运行任务”“分配”；池到观测节点（x=8.55、y=5.15、w=3.85）连接“结果/时延/失败率”；反馈虚线回调度器，标“达到限流阈值时暂停分配”。
- **解释/条件**：图下文案“分配减少空闲是否转成整体吞吐，要看排队、下游和重试；F1只说明配置下的结果，不能证明单一机制因果”。没有证据就不写“调度带来2倍收益”。
- **来源/模式**：页脚“虚构教学架构，流程示意；性能证据另见F1/第2页”。live 按箭头顺序逐步讲解，最终静态页保留完整路径；read 加简短节点定义、异常/回退路径说明，不能依赖动画才理解。
- **阅读顺序/适用/拆页条件**：入口到工作池 → 观测反馈 → 限制；用于建立机制心智模型。若需解释重试状态机或下游竞争，保留本全景并另页放大，不把所有故障支路塞进全景。

## 5. 比较矩阵：让同一标准导出选择

- **页面文案**：标题“B 汇总指标过线，联合达标待逐次复验”。
- **布局/对象**：原生表 x=0.55、y=1.75、w=12.2、h=3.7；四列宽3.5/2.4/2.4/3.9 in，分别为“标准及单位 / A / B / 对决策的含义”。

| 标准及单位 | A | B | 对决策的含义 |
| --- | ---: | ---: | --- |
| 吞吐≥150任务/分钟（合成中位数） | 120，未过线 | 160，过线 | 汇总值用于候选筛选 |
| P95≤6秒（合成中位数） | 8，未过线 | 5，过线 | 与吞吐、失败率须同窗口复验 |
| 失败率≤1%（合成观测） | ≤1%，达到 | ≤1%，达到 | 此项不能区分候选 |
| 年化运行成本（估算，万元） | 28 | 44 | B比A高16，收益未量化 |
| 联合验收 / 生产代表性 | 均未验证 | 均未验证 | 不能直接批准生产扩容 |

- **解释/行动区** x=0.55、y=5.7、w=12.2、h=0.55：“据此只建议 B 分阶段试点；上限8万元，同窗口联合复验F2及合规/回退通过后才放行下一批预算”。页脚列“虚构教学数据｜F1/F2/E1，各自日期及口径 → A1”。状态用“过线/未过线/未验证”文字，明确汇总筛选与联合验收的区别；不能用绿勾把估算当成事实，不造没有权重依据的总评分。
- **模式/阅读顺序**：live 先看两项决定性差距，再说明成本与未验证项；必要时先用高亮聚焦，最终页仍可读。read 保留表内单位、门槛、状态和各自来源/条件，在页下解释为什么未选较便宜A。按“标准→数值→含义→行动”读取。
- **适用/拆页条件**：候选共享评价口径的资源选择。若候选或标准过多导致口径与值无法并读，先做主决策矩阵，再把完整规格移附录；缺失值写“未验证/未知”而非零。

## 从例子迁移到真实交付

这些规格要先替换虚构来源与数据，再根据 brief 和模板构建、渲染、试读/试讲。核对数据与图形应保留 [图表检查](chart-integrity.md) 的测量记录；规格中的坐标与字号仅证明布局意图，不证明实际字体替换、换行、比例、可编辑性或阅读效果已通过。
