# 研究汇报演示

与 `Presentations` 组合使用。按研究问题组织而不是按论文目录照搬：问题与缺口 → 核心主张 → 方法/材料 → 关键结果 → 替代解释 → 局限 → 意义与下一步。

按 [live/read/hybrid 使用模式](../presentation-studio/references/authoring-modes.md) 编排与验收；自阅结论和方法边界不能只藏在备注。沿用 [evidence-ledger / storyboard](../presentation-studio/references/contracts.md)，区分原始观测、估计、推断和建议，用证据支持解释，连接下一实验/核验动作与成立条件；无充分证据时不把相关性或探索性结果升级为应用建议。无需每页重复四格。

- 区分用户自己的结果、引用结果和假设；每项关键结果可追溯到图表、表格或文献。
- 图表保留轴、单位、样本量、误差表示和必要统计信息；不从图片中猜精确数值。
- 方法页只讲理解结果所必需的设计；补充细节进入附录。
- 一张结果页回答一个问题，标题表述被数据支持的发现。
- 负面结果、失败实验和不确定性不能因叙事需要被删除。
- 备注准备方法质疑、外部效度、数据限制和可复现性问题。

需要发现新论文时先调用相应专业研究 Skill。有参考作品时读 [参考转译](../presentation-studio/references/reference-translation.md)；定量图按 [图形真实性](../presentation-studio/references/chart-integrity.md) 复核，保留上述研究特有统计信息。

基础渲染验证由 `Presentations` 完成；用户要求独立审阅/修复，或涉及高风险决策、关键定量结论及复杂改版时加载 `deck-review`，重点检查引用、结果忠实度和图表可读性。
