# 数据报告演示

与 `Presentations` 以及适用的 Data Analytics Skills 组合使用。先锁定指标定义和可信数据，再采用：结论摘要 → 目标与实际 → 变化位置 → 已验证驱动 → 影响 → 建议动作 → 监控计划。

按 [live/read/hybrid 使用模式](../presentation-studio/references/authoring-modes.md) 安排信息层与验收；有参考作品时读 [参考转译](../presentation-studio/references/reference-translation.md)，定量图表读 [图形真实性](../presentation-studio/references/chart-integrity.md)，分别检查来源/条件位置、可编辑对象和数值到图形的映射。

- 每个 KPI 写清公式、时间粒度、范围和目标；不同口径不可直接比较。
- 图表标题表达发现，轴、单位、基准和来源完整；预测与实际使用不同编码。
- 异常相关性不能写成因果。驱动因素按“已验证、可能、未知”分层。
- 表格用于精确查阅，图表用于关系和趋势；不要把原始数据表缩小贴到正文。
- 页面先显示重要变化，再提供解释和行动，不让观众自行寻找结论。
- 备注保存查询口径、过滤条件、更新时间和可复现链接。

基础渲染验证由 `Presentations` 完成；用户要求独立审阅/修复，或涉及高风险决策、关键定量结论及复杂改版时加载 `deck-review`，重点检查数据一致性、图表诚实性、可编辑性和行动闭环。
