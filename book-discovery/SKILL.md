# 找书与版本核验

交付符合需求的书目、具体版本、可核验入口及访问状态。研究任务只有读到相关正文后才形成内容证据。

## 界定任务

- 区分明确书目、主题选书、查某段论述、获取文件。沿用已有语言、版次、用途和来源偏好；只有同名书或版本差异会改变结果时才澄清。
- 主题找书提供少量互补候选，解释适用人群与选取依据；不能仅按热度排序。
- 用户指定 Z-Library 等来源时先查指定来源，以出版社、作者或图书馆记录补核身份，不擅自替换指定产品。
- 未指定来源时按 [来源选择](references/sources.md) 路由。中文覆盖不足时切换中文书名、作者、译者、出版社目录；单一目录零结果不证明不存在。

## 推荐后的阅读入口

- 个性化荐书沿用用户已授权使用的偏好和上下文，信息足够就先给候选，不为完成固定问卷反复追问。
- 书单确定后默认继续为首选书目补查实际阅读/借阅/获取入口；用户明确只要书单或观点时无需扩大任务。多个版本无法确定时说明选用版本或歧义。
- 分开“书目核验链接”和“阅读/获取链接”。豆瓣、书评、出版社介绍或普通馆藏记录通常只能核验书目；只有实际提供预览、借阅或获取功能且已观察到时才标为对应入口。
- 沿用本次任务已经明确的书源偏好。用户指定 Z-Library 时尝试当次可核验入口；无法检索或登录时逐项说明已尝试的入口及阻碍，不能只给其他站介绍页后称为完成。
- 书籍详情页、站内搜索页与平台首页分开标注。没有查到书籍页时可给明确标注的搜索入口，不拼接未经验证的 ID，也不把首页说成该书链接。
- 最终交付包含首选书目的推荐理由、具体版本、阅读入口和访问状态。入口未验证时明说“仅核实书目，阅读入口未验证”，不等用户再次追问。

## 查找与核验

1. 先发现可用的连接器、API、已授权浏览器或本地书库。已有能力足够就不安装新 MCP、不建立新账户。
2. 若有 research-toolkit，可从该技能目录运行标准库脚本：
   - `python -B scripts/bookctl.py search --query "<查询>" --limit 5`
   - `python -B scripts/bookctl.py search --title "<书名>" --author "<作者>" --language "<三字母语言码>"`
   - `python -B scripts/bookctl.py lookup --isbn "<ISBN>"`
   - `python -B scripts/bookctl.py lookup --olid "<版本 OLID>"`
   当前脚本只查询 Open Library 公开书目；Z-Library 等用实际可用工具，不把脚本描述成全站搜索器。工具层缺失时用连接器或浏览器，保留相同字段。
3. 分开作品、出版版本、文件副本。同一作品的不同语言、译者、修订版和卷册不能当作可互换版本。ISBN 校验位正确只证明格式有效。
4. 优先匹配作者、完整书名、版次/译者、年份和 ISBN，再选文件格式。指定版本未找到时明确标为替代版本，不自动下载第一条结果。
5. 出版年、出版社、ISBN 必须来自同一版本，不能拼接作品聚合字段。作品级参与者可能混合作者、译者、配音者，需核对具体版本角色；载体可能是有声书或摘要版。无法交叉确认时保留未知或冲突。
6. 分清仅书目、有限预览、可借阅、需要账户、可访问全文、失败/未知。目录声明或下载链接不等于已拿到可读全文，记录实际观察日期。

## 获取与阅读

- 找书通常到候选和入口为止；用户要求获取时，沿用已有授权获取可合法访问的文件。登录、付费、DRM 或验证码阻碍时报告具体状态，不绕过限制。
- 来源身份和会话处理见 [来源选择](references/sources.md)。入口或会话未核实时继续书目核验，标记该来源未实测，不声称已搜全。
- 保存到用户选择或任务产物目录，保留已有文件。下载后核验文件类型、可打开性、版权页/目录和相关章节完整性；实际保存后再计算哈希。网页错误内容不能当 PDF 验收。
- 需版面/页码核验时调用可用 PDF 能力；EPUB 使用章节标题和段落定位。PDF 文件页序与印刷页码分别记录。
- 只读解决问题需要的目录和章节。全文获取、文本抽取、相关段落核验分别报告；全书可访问不等于全书已读。

## 交付与证据交接

普通找书输出简洁候选表：题名/作者、版本与语言、匹配理由、书目核验链接、阅读/获取入口、访问状态、未核实项。书目与阅读链接分别标注用途。

交给 evidence-research 或专业研究技能时附：
- 书目身份：作品、版本、ISBN/其他标识符、出版社、译者、年份。
- 来源：书目核验 URL、实际获取 URL、获取时间；文件路径与哈希如有。
- 阅读范围：metadata_only、preview、excerpt 或 full_text；另列实际核验章节/页码。
- 正文证据：原文定位、支持的主张、必要短引文、适用范围与缺口。只有元数据时不填写正文主张。
- 同一本书经不同站点获取仍是一份来源；书中转引的实验、统计或政策尽量追溯原始材料。

机器字段在 research-toolkit 的 references/book-evidence-schema.md；没有该技能时以上字段足以交接。平台负责获取，证据权重由原书作者、方法、版本和问题相关性决定；镜像不提供独立佐证。

遇到作品聚合或载体错配时，可按需看 [目录边界实测](example/catalog-boundaries.md)，历史结果不作为当前默认书目。

## 停止条件

同一访问错误查明原因后最多再试一次，再切换有依据的来源。明确书目及可用入口满足需求后停止；没有命中或版本未核实时报告已查来源、检索词、失败类型与缺口，不把搜集任务原样交回用户。
