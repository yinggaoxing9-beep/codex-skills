# Alpha 猜想研究

把“某种现象之后可能发生什么”变成可证伪的候选，保留定义、证据和研究状态。研究型收益预测、风险预警与可执行策略是不同产物，按用户本次要求完成相应层次。

## 范围与分工

- 用户仅要求猜想或明确“不用验证”时，生成候选和待验证命题；不自动运行回测。用户授权实现或回测后，主动审计可用数据、实现并运行范围内的研究，不把可自行完成的搜集工作交回用户。
- 独立数据查询、实现和审查可并行；依赖数据口径、冻结定义和最终结论保持一致。记录未完成与失败的尝试，避免只保留赢家。
- 回测授权不包含通知、持续监控或真实交易。既有注册表的生产准入机制保留；无意外隐式激活。

## 从猜想到可计算定义

1. 明确目标、期限和方向：预测较差的相对收益、触及某种风险，还是扣费后退出再入更有利。使用实际决策需要的目标，不把“见顶”事后标签作为信号输入。
2. 逐条记录稳定ID、经济机制、可计算公式、数据字段、可得时点、观察窗口、触发与解除条件、失效情形。把含糊叙述变成操作化版本，并说明相对原猜想的缩窄或代理关系。
3. 审计数据能力：历史股票池与退市、交易日历、复权版本、字段单位、缺行与重复、公告/行业/预期的PIT可得日期。只有日线时，不能冒充分钟行为；只有当前行业名单时，不能回填历史行业。
4. 缺字段或缺窗口返回未知与具体原因；不以false、零值或启发式代理伪装完整验证。无法测试记“缺数据未检验”，样本不足与方向不支持分别记录。
5. 运行前保存不可变定义、数据指纹、代码及环境版本、股票池、切分、随机种子、主要终点、交易成本和试验预算，同时声明放弃条件及允许的修改范围。更改规则生成有父实验ID的新版本，记录为什么修改，不覆盖原失败结果。

## 检验与反证

- 信号只用决策时点可得数据。用截断及未来扰动测试检查过去信号不变；标签计算与信号计算隔离。按统一交易日历对齐，缺行情不顺延持有周期。
- 先评估警报事件：定义成熟窗口、重复信号冷却、可评分条件及适当对照。警报没有大跌也可能跑输对照；命中率高也可能只是同期市场都在跌。共同时间、风险状态和可得数据是对照起点，行业/规模/波动差异未匹配则披露混杂。
- 事件先选择，再检查未来是否可评分、可成交；保留不可评分与执行失败事件及覆盖率，不通过删除坏事件制造好结果。处理持有期重叠、同日股票相关与时间序列依赖；报告效应大小及区间，不只排名或p值。
- 区分探索、时间留出与真正未接触的验证。已知个人交易或顶点用于说明，不充当独立OOS。按标签成熟时间清除跨界泄漏；筛选过的留出数据下一轮属于已使用数据。PIT审计覆盖整个研究环境：搜索结果、公告版本、历史记忆和LLM已有知识都可能包含未来；仅冻结行情不能宣称全流程无泄漏。无法隔离时标记历史探索。
- 多重检验预算包含尝试的规则、方向、期限及参数分支；方法与预算在看结果前声明。具体检验数属于本轮设计，不固化为通用常数。
- 搜索反证：跨年份/市场状态/股票的稳定性，错过继续上涨的代价，费用及延迟敏感性，对照选择影响，以及对已有信号的增量和重合。参数邻域检查是稳健性研究，仍计入尝试记录；不能靠反复调整直到某个历史顶点报警。

## 从事件证据到策略

报警组相对较弱，不等于退出有盈利。进一步结论需要明确交易规则、成交时点、涨跌停/停牌、手续费/滑点/税费、最低费用与整手、资金占用和退出后回补，再构建连续账户净值。条件性单事件避险收益不能冒充组合收益或最大回撤。

软件单测、历史研究、影子运行和生产批准分别记状态。支持证据仅允许进入项目既有的下一研究阶段；缺数据、证据不足和失效均保留可追溯记录。新数据或用户修订目标后，创建新研究版本并重新评估。

经验沉淀保留完整研究轨迹：猜想来源、读取的信息、工具调用/代码、运行、失败、反证和最终决策。一次成功只形成案例；跨多个独立轨迹仍有效才提升为通用经验。具体产物留在项目，技能仅沉淀用户要求复用且经核验的规则。

交付覆盖全部候选：定义/输入状态、样本覆盖、效应与不确定性、反证、执行边界、数据代码指纹和可复现入口。结论使用“初步支持 / 未见支持 / 方向相反 / 样本不足 / 缺数据未检验”等明确状态，不能将未拒绝零假设写成“证明不准”。

接入已有代码库时，按需读[项目适配契约](references/project-adapter.md)。只在对应仓库续做时读[量化工程适配记录](example/quant-engineering.md)，其中参数和历史结果均不作为其他任务默认值。

## 规范命名与交接

任何小想法可保留为 idea；期限或定义未定时不强行正式命名。正式因子名为 `Alpha_<N>Day_<semantic_slug>`，N 是未来交易日期限，lookback、version 与机制家族独立保存。项目注册表命名不兼容时保持待适配，不自动小写或改动既有 ID。

需要连接个股分析时由 investment-research 编排；跨步骤交接复用 已安装的 research-toolkit 的 references/handoff-contract.md 外层 与原生 registry 引用。先按用途、周期、条件和资格核对；候选产生不授予生产资格，生成器不能自行 ACTIVE，组合分数和主观投票不能冒充校准概率。
