# 回复与后续选择

## 先定位实际卡点

判断当前困难来自资料展示、开场、连续问答、情绪没有接住、现实安排或投入不对等。问题不同，下一步也不同；更花哨的句子未必有用。
对方为办事而联系时先把事情说清楚，不把认真答复直接解释为恋爱兴趣。

## 编排一条消息

- 内容层交代正在问的事实、时间或选择。
- 语气层可用具体观察、轻松幽默和用户平时的语气词。
- 关系层可表达理解、欣赏或愿意继续了解。
按需要取用，不强制凑齐三层。邀约以可执行安排为主，倾诉以回应当事内容为主。
表达长度和熟悉度相称；不把已有一个表情的回复扩成心理分析。

## 怎样接后续

| 可见反馈 | 可考虑的下一步 |
| --- | --- |
| 主动展开、反问或分享新细节 | 接住新内容，分享自己或继续了解 |
| 明确接受活动、提供日期或替代方案 | 核对双方可行时间与地点，具体化安排 |
| 简短礼貌、含糊或忙 | 按上下文收尾、留空间；不从一次短回复确定动机 |
| 持续单边追加、反复取消且没有替代安排 | 降低投入，必要时澄清；不把补话术当唯一解法 |
| 明确拒绝、要求停止或表达不适 | 停止当前方向，尊重退出 |

这些是选择依据，不是确定的读心信号。更新判断时同时看相反证据。

## 邀请

有合适的双向背景时，提一个具体活动和可协商窗口；时间地点尚未明确就给待选方案，不能替双方确认行程。
对方有困难时接受改变或拒绝。一次不方便不等于永远不愿意，愿意见面也不等于确认关系。
避免用假的共同经历或假期限制造理由；用户可以直接表达想了解对方。

## 演练与复盘

用户要求模拟时，先说明这是练习。依据有限信息模拟一种可能的回复，不冒充对方真实想法。
每轮聚焦一个能力：回应内容、分享自己、轻松表达、具体邀约或自然收尾。
复盘指出哪句话有依据、哪里给对方回应空间、哪里仍未知。不要用虚构分数或模板命中数证明效果。
可参考[回复分支演练](../example/reply-branches.md)，实际任务不照抄示范。
