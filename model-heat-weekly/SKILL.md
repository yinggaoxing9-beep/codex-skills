# 模型热度周报

完成可追溯的中文研究、数据核验和成稿，默认交付 `.md`、5张PNG以及MD配图包。用户要求写入飞书并指定目标时再同步。正文与图片共用同一份数据，OpenRouter用量始终第一节。

## 先确定周期

- 用户指定起止日期均包含当天。运行 `scripts/period.py` 计算完整日数、边界和前一等长周期，不能只换标题日期。
- 默认OpenRouter采用UTC完整日，同时列北京时间。用户明确要求北京时间时遵从；来源不支持该窗口时说明缺口，不能给UTC日桶换标签冒充北京时间。
- 未指定日期：“最近完整7天”以客户端当前时刻换算UTC，排除尚未结束的UTC日；不用执行主机本地日期。只有客户端日期而无时刻时读取当前时刻。来源延迟时分别保留目标周与实际来源周，不静默平移或将旧榜写成目标周。
- 23—29日含7个完整日期，对应 `[23日00:00,30日00:00)`，基期16—22日。22—29日含8个完整日期。用户称周报却给8天时，简短确认日期，同时继续不依赖边界的工作；脚本拒绝非7天，用户明确需要非周区间才用 `--allow-nonweekly`。
- 累计快照相减须写两个完整时间点及实际间隔；“相隔约7天”不等于“覆盖7个完整日期”。提交时间不自动等于逐仓采样时间。

## 调研与分工

1. 阅读 [统计与来源](references/research-methods.md)，保存本期brief：周期、时区、基期、模型范围、实际来源窗口、目录和交付目标。已有项目优先沿用，在独立期次目录保存原始响应、采集时间、来源URL、计算记录与最终稿。
2. 用户此前偏好并行。工具与授权允许时按五板块委派明确角色的子代理，偏好GPT-6 Astra、xhigh；槽位不足分批。代理只写自己的目录，总编辑独占主JSON、配图和外部文档。不可用时直接完成，不声称已创建。只有用户明确要求侧栏新对话才调用对话工具。
3. 委派包含共同周期、身份/许可规则、字段、证据目录和返回格式。跟踪完成/阻塞状态，先取得用量模型ID，再让能力代理精确对齐；其他板块可同时进行。
4. 查当期一手来源，核验字段和方法。优先公开API、模型卡、官方发布与固定历史归档，搜索仅作线索。不得从模板/上一期复制数值、榜位、窗口或许可结论到新一期。
5. 尽力查历史快照、固定提交及公开历史接口补齐数据；仍不可得保留 `—` 和具体原因。缺值非0，未入前50非没有用量。不能证明全市场覆盖就标候选范围。

## 固定呈现

读取 [版式与简析](references/presentation.md) 和 `assets/layout-contract.json`。`assets/templates/` 的五张原始模板只提供样式，其日期、模型及数值不能作事实来源。

- 五节顺序、主标题、标签、40个表头固定；实际模型、排名、数值按本期数据算。“保持一致”指表达和版式，不是沿用榜位。
- 全球/中国分别取前10、独立排序，全球可包含中国，两侧不去重。中国栏默认中国机构官方公开权重，许可限制另记，不宣称严格开源认证。新品不足10个/中国为空留横线，不凑数。
- 能力图默认对照第一节热门模型，排名和行序沿用实际用量榜，说明不是能力排名。用户明确要按能力另排时再改，并标明指标。
- 每图保留“本期简析”3条，解释榜首、中国席位/占比和值得关注的变化，限定样本/时间/指标。详细写法见参考。
- 口径放在**图片外下方的“图表说明”**：来源链接、采集时刻、实际窗口/时区、基期、公式、平台返回或自行复算、范围/空值含义。图内不放底部灰色脚注或“数据与链接详见Markdown正文”。
- 首次解释“智力”：AA即Artificial Analysis综合评测指数，非人类IQ或正确率；不同版本/推理配置不直接比。模板“官方基准”标签不改变AA第三方身份。

## 制作与检查

读取 [数据结构与脚本](references/data-and-rendering.md)，生成 `report-data.json`。图下说明必须来自当期证据，不能未核验就复用旧说明。

```text
python <skill>/scripts/period.py --start YYYY-MM-DD --end YYYY-MM-DD
node <skill>/scripts/render.cjs --data <issue>/report-data.json --out <issue> --module-dir <bundled-node-modules>
```

用 `load_workspace_dependencies` 找运行时，不写死缓存版本。脚本输出绝对图片路径版MD、`portable/` 相对路径版MD、PNG/SVG与验证结果。压缩portable目录后和MD一并交付。

核验真实排序/筛选、窗口、分母、变体映射、AA版本和图文一致性。5图都检查标题、表头、排名、长名称、简析换行、负号和空值；数字不得被截成省略号，必要时缩写单位/小数或调字号。脚本不代替事实核验。
