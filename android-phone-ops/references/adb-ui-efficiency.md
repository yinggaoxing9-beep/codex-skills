# ADB UI 操作提速与草稿恢复

适用于长时间手机 UI 操作。先量测少量代表性调用，不凭总耗时估算各项占比，也不把无操作命令的提速倍数推广到输入或完整任务。

## 优先消除返工

- 先确定整条文案和已知事实，再打开键盘输入。候选词错、光标位置不可靠或修改会波及多行时，确认是己方未发送草稿后，一次全选清空、验证为空、输入修订后的整段，避免连续局部删改。
- 一个能准确定位的错字可局部修正；整段重输不是所有错误的强制规则。用拼音第一候选重输时，应先调整短句切分或输入方法，否则可能重复相同错误。相同错词再次出现时，停止沿用该输入方案，不无限重试。
- 不删除已发送消息来重发。断线、超时或工具审批等待后，先核对消息历史和当前草稿；确认发送状态之前不补发。
- 全选/删除只作用于当前核对的接收方及草稿，先记录并核对原文，确认输入框已聚焦。多行编辑器的行首键不能替代全文选择；全选后读回空草稿再继续。

## 减少输入调用

- 优先复用已经授权且核实身份的整句 Unicode 输入接口。输入助手安装前检查来源、包名、版本与证书；历史授权不等于本次安装已成功。
- 临时输入法只在单次输入调用内切换：切换前记录当前默认输入法，将切换与输入放在 `try` 中，在 `finally` 中尽快恢复原输入法并读回核验；恢复完成后再进行后续页面读取、发送或等待。不要一直保持临时输入法到整轮任务结束，也不要把某个品牌或历史值当作原输入法。恢复失败要立即报告，不能仅因已执行恢复命令就声称完成。
- 用户预告暂停、拔线或要求交还手机时，仍连接就先恢复原输入法并核验，再按约定移除临时助手。若已经断连，记录尚未恢复的状态并明确告诉用户；必要时请用户点击系统的输入法切换按钮选择原键盘，或在系统设置的输入法管理中切回，具体入口以当前系统为准。连接恢复后再核验和清理，不声称断连期间已恢复。
- 原生拼音坐标输入前确认当前文字键盘、布局和稳定位置。表情面板可能占同一区域，点击可能立即发送。
- 先验证整个输入计划的字母、标点及坐标，再执行第一步。后面的非法参数不能在已经输入一半后才发现。
- 顺序且已授权的点按可按短句合并进一次 ADB shell，数字坐标与限定指令由脚本生成，失败即停；不能把任意文案拼接成 shell 代码。合并减少主机往返，设备上的每次 input 调用成本仍存在，候选准确度也不会自动改善。
- 输入与发送分开。输入结束读回完整实际草稿，与预期全文比较；不匹配就留在草稿，禁止自动发送。不要用任意命令常驻服务规避审批。

## 按需读取页面

- 同一稳定页面只读取一次所需树，在没有导航、输入、键盘或新消息变化前复用；导航或可能改变坐标后重新读取。
- 将 dump 和 cat 合并为一次 ADB 调用，使用本次唯一临时路径，校验返回码和 XML 层级。清理本次生成文件；dump 失败不能读取旧树。
- 默认输出任务所需字段。查接收方、草稿和按钮用树；确认照片、文字键盘、布局或树含糊时再截图。浏览照片仍要看截图。
- 截图失败或 pull 失败时，不能显示本地旧文件。调用方检查成功后再查看图像。导航后的空树/转场树只做有限重读，不连续盲点。
- 消息列表会因新消息重新排序；用当前昵称/控件 bounds 定位，不复用旧行坐标。设备连接也需当前 serial，脚本不静默回退历史无线地址。

## 保留必要核验并记录耗时

保留进入会话后的接收方确认、发送前当前接收方与完整草稿确认、发送后己方气泡确认。审批等待后重新获取 UI；发送状态不明先查记录。表情等点即发送的控件要在点击前完成内容和接收方确认。

计时分别记录主机 ADB 调用、dump/读取、截图/传输、输入、草稿纠错、审批与断线等待。改善报告区分已经实测的耗时、静态可确定的调用数量下降、尚未验证的输入准确性与完整任务收益。不要为了统计再次跑完整社交任务。

## 输入约束与临时工具的生命周期

- 输入方式是实现细节，不得为适配工具而擅自改变用户指定的语言、语气或内容。原方案失败时，选择仍满足约束的输入方式；确需手机侧操作时明确提示。用户纠正会覆盖尚未执行的旧计划，继续前核对在途命令与草稿。
- 区分输入法的启用状态与助手的安装状态。每次输入后恢复原输入法；在用户允许的同一轮任务内可保留已核验的助手，避免每条消息反复卸载安装。按用户约定在整轮任务结束或交还、断开前清理，短暂等待回答不自动等同任务结束。状态记录同时写明当前默认输入法和临时包是否安装。
- 输入失败后先找原因，再决定重输。原生输入反复丢字时改用可靠的 Unicode 通道，不通过修改预期文本去掩盖输入故障。内容确需修订时重新审阅修订后的全文，再走正常发送核验。
- 接收方核验应在临时切换输入法之前完成；输入中仍保留目标与草稿核验以及 finally 恢复。安全退出并恢复成功是保护措施生效，不代表该操作已完成。
